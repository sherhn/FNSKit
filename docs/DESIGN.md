# Дизайн ФНСКит

Справочник для тех, кто делает новые страницы и блоки. Всё описанное здесь взято
из кода в `site/`; если код и этот файл расходятся, прав код, а файл надо
поправить.

Образ интерфейса: **чернила на бумаге с двумя акцентами** — тёплый светлый фон с
едва заметной точечной сеткой, чёрный (ink), лайм и фиолетовый. Крупная плотная
типографика, большие скруглённые карточки, никаких теней-«облаков» кроме двух
мягких. Интерфейс спокойный и деловой: документы, сроки и подпись — тема
напряжённая, поэтому визуально не добавляем шума.

## 1. Как устроен сайт

Сайт — статические HTML-страницы без фреймворка. Сборка нужна только для CSS и
JS.

| Что | Где | Заметки |
| --- | --- | --- |
| Страницы | `site/*.html` | Один файл — одна страница. Чистый адрес без `.html`: `/privacy` отдаёт `privacy.html`, а `/privacy.html` редиректит (301) на `/privacy` |
| Утилитарный CSS | `site/src/tailwind.css` → `dist/css/tailwind.css` | Tailwind 3.4.19, конфиг в `site/tailwind.config.js`, сканирует `./*.html` и `./js/**/*.js` |
| Готовые компоненты | `site/style.css` | Классы статьи (`.article-*`), юридических страниц (`.legal-*`) и общих блоков (`.note`, `.steps`, `.inline-cta`…) |
| Мобильная правка | `site/mobile.css` | Минимальные размеры касания, диалоги, правки шапки. Комментарий в шапке файла устарел: Tailwind давно собирается, а не грузится с CDN |
| Шрифт | `site/fonts.css`, `site/fonts/manrope-variable.woff2` | Manrope, переменная ось веса 200–800, хостится у нас |
| JS | `site/js/*.js` → `dist/js/*.js` | Минификация terser, имена файлов сохраняются |
| Сторонние библиотеки | `site/scripts/build-js.mjs` | `utif` и `pdfjs-dist` копируются в `dist/vendor/` с версией в имени |
| Образ | `site/Dockerfile`, `site/nginx.conf` | Статика внутри образа nginx; правка HTML, CSS или `nginx.conf` требует пересборки |

Сборка и проверка локально:

```bash
cd site
npm ci
npm run build          # dist/css/tailwind.css и dist/js/*
npm run watch:css      # пересборка CSS при правках разметки
```

Весь стек вместе с сайтом: `docker compose --env-file .env -f backend/docker-compose.yml up --build -d nginx`,
сайт откроется на `http://localhost:8082`.

### Правила, которые нельзя нарушать

- **CSP жёсткая** (`site/nginx.conf`): `script-src 'self'`, `connect-src 'self'`.
  Нельзя ставить inline-скрипты, обработчики `onclick=`, внешние скрипты, CDN,
  шрифты и картинки с чужих доменов. Inline-`<style>` и атрибут `style` пока
  разрешены (`style-src 'unsafe-inline'`), но новые стили лучше класть в
  `style.css` или писать утилитами Tailwind.
- **API только своего origin.** Адрес процессора задаёт `js/config.js`
  (`window.FNSKIT_PROCESSOR_API`), в продакшене это `/api/processor`. Прямых
  адресов в коде нет.
- **Никакой внешней загрузки при открытии страницы.** Шрифт и библиотеки раздаём
  сами: внешний запрос передаёт IP посетителя третьей стороне, а политика ПДн
  утверждает, что такой передачи нет.
- **Классы Tailwind должны быть в исходнике целиком.** Сборка сканирует файлы и
  не видит классов, склеенных из частей (`"bg-" + color`). В JS пишите полные
  строки, как в `showCreateMessage()` в `js/editor.js`.
- **Кэш-версия вручную.** Ссылки на CSS и JS несут `?v=…` (например
  `./js/editor.js?v=20261017-free`). Меняли файл — меняйте и версию во всех
  страницах, которые его подключают, иначе браузеры останутся на старом.

## 2. Цвета

Токены заданы дважды: в `tailwind.config.js` (классы `bg-ink`, `text-lime`…) и в
`:root` у `style.css` (переменные `--ink`…). Меняя значение, правьте оба места.

| Токен | Значение | Роль |
| --- | --- | --- |
| `ink` | `#171815` | Текст, тёмные карточки, основные кнопки, тёмная боковая панель редактора |
| `paper` | `#F5F4EF` | Фон страницы, внутренние панели |
| `lime` | `#C8FF32` | Главный акцент: фон hero статьи, галочки, номера шагов, шеврон на тёмной кнопке, выделение текста |
| `violet` | `#7C68FF` | Второй акцент: подписи-eyebrow, точки, ссылки при наведении, фокус, левая полоса «ошибок» |
| `mist` | `#E9E8E2` | Нейтральная подложка (используется редко) |

Цвета без токена, которые уже есть в разметке. В новом коде берите их как
`bg-[#DDD9FF]`, а лучше заведите токен в конфиге:

| Значение | Роль |
| --- | --- |
| `#DDD9FF` | Бледно-фиолетовая поверхность: `.note`, карточки «регистрации», профиль «НДС» в редакторе, CTA-блок на главной |
| `#FFDFA8` | Тёплая поверхность профиля «Кастомный TIFF» |
| `#F0EDFF` | Напоминание про «Спам» (`.spam-reminder`) |
| `#4F6BFF` | Служебный синий в редакторе: выделение и перетаскивание страниц. В новых страницах не использовать |
| `#C8FF18`, `#D8FF58` | Контуры маркера `.hero-emphasis` на главной; почти лайм, но не он |

Прозрачность — основной способ строить иерархию, а не новые цвета:

- основной текст — `text-ink`; вторичный — `text-ink/60`, подписи — `text-ink/40`–`/45`,
  неактивное и подсказки — `/25`–`/35`;
- границы — `border-ink/10` (усиленные — `/15`, `/25` при наведении);
- стекло — `bg-white/70` или `/85` с `backdrop-blur`.

Состояния:

| Состояние | Классы |
| --- | --- |
| Успех, подтверждение | `bg-lime text-ink` (плашка), галочка в `bg-lime` |
| Ошибка | `bg-red-50 text-red-700`, рамка `border-red-200/300`, подсказка `text-red-600` |
| Нейтральная плашка | `bg-[#DDD9FF]` |

Красный используем только для ошибок. Зелёного акцента нет: «хорошо» — это лайм.

Раскладка цветов по поверхностям: в сетках карточек чередуем **лайм → бледно-фиолетовый
→ ink** (так сделаны карточки инструкций на главной). Тёмная карточка получает
`text-white` и лаймовый шеврон или eyebrow.

## 3. Типографика

Шрифт один: **Manrope**. В Tailwind это `font-sans`, запасной — Arial. Файл
переменный, вес задаётся любым значением 200–800.

| Роль | Вес | Размер | Трекинг |
| --- | --- | --- | --- |
| Логотип-слово | 900 (`font-black`) | `text-lg` | `-0.07em` |
| H1 главной | 900 | `clamp(3.35rem, 6.2vw, 6.8rem)`, `leading-[.9]` | `-0.085em` |
| H1 статьи и юридической страницы | 900 | `clamp(42px, 6vw, 78px)` / `clamp(38px, 6vw, 72px)`, `line-height .95` | `-0.075em` / `-0.07em` |
| H2 секции главной | 800 (`font-extrabold`) | `text-4xl sm:text-5xl` (до `sm:text-6xl`), `leading-[1.02]` | `-0.06em` |
| H2 статьи | 800 | `clamp(27px, 3vw, 38px)` | `-0.055em` |
| H3 | 800 | 19–36 px по контексту | `-0.035em`…`-0.055em` |
| Eyebrow над заголовком | 800–900 | 11–12 px, `uppercase` | `.14em`–`.18em`, цвет `violet` или `ink/45` |
| Абзац статьи | 400–500 | 16 px, межстрочный 1.78 | обычный |
| Абзац юридической страницы | 400 | 15 px, 1.72 | обычный |
| Лид | 600 | `clamp(18px, 2vw, 23px)`, 1.55 | обычный |
| Подписи и бейджи | 800 | 9–12 px, `uppercase` | `.08em`–`.14em` |

Правила:

- Заголовки плотные: отрицательный трекинг и межстрочный меньше единицы. Не
  ставьте крупные заголовки с обычным трекингом.
- Всё мелкое капсом (eyebrow, бейджи, подписи к цифрам) идёт с положительным
  трекингом, иначе нечитаемо.
- Числа и единицы пишем слитно по-русски: `300 DPI`, `1 бит`, `CCITT G4`,
  `100 МБ`. Деньги — через `Intl.NumberFormat("ru-RU", { style: "currency", currency: "RUB" })`.
- Название продукта пишется **«ФНСКит»** по-русски везде, где это название для
  человека: заголовки, тексты, письма, подписи к картинкам. Латиница `fnskit`
  остаётся в идентификаторах: пути, образы, имена переменных, логгеры.

## 4. Сетка, отступы, ширины

Контейнеры страниц:

| Страница | Контейнер |
| --- | --- |
| Главная, секции | `mx-auto max-w-[1440px] px-5 sm:px-8 lg:px-12` |
| Редактор | `mx-auto max-w-[1920px] px-5 sm:px-8 lg:px-10` |
| Просмотрщик TIFF | `max-w-[1240px]` |
| Статья | `.article-shell`: `min(1240px, 100% - 40px)`, колонки `minmax(0,1fr) 280px` |
| Юридическая страница | `.legal-layout`: `min(1180px, 100% - 40px)`, колонки `minmax(0,1fr) 260px` |

Ритм: секции главной — `py-24 lg:py-32` (на странице статьи секция отделена
`border-top` и отступом 32 px). Блоки внутри — `gap-3`…`gap-5`, между крупными
карточками `gap-5`.

Брейкпоинты Tailwind по умолчанию: `sm 640`, `md 768`, `lg 1024`, `xl 1280`. Чаще
всего используются `sm:` (158 раз) и `lg:`. Компоненты из `style.css` перестраиваются
на 900 px (боковая колонка уходит под статью, оглавление скрывается) и на 640 px
(уменьшаются отступы и радиусы); `mobile.css` добавляет правки до 380 px.
Проверяйте страницы на 375, 640, 900 и 1440 px.

## 5. Форма: радиусы, границы, тени, декор

**Радиусы** (чем больше блок, тем больше радиус):

| Радиус | Где |
| --- | --- |
| `rounded-full` | Кнопки, бейджи, чипы, точки, поля со ссылками |
| `rounded-[2rem]` (32 px) | Крупные карточки и секции главной; `.legal-document` 32, `.article` 34 |
| `rounded-[1.45rem]`–`[1.7rem]` | Панели внутри больших карточек |
| `rounded-2xl` (16 px) | Малые карточки, плашки, дропзона |
| `rounded-xl` (12 px) | Поля ввода, кнопки внутри форм, плашки сообщений |
| `rounded-lg` | Мелкие элементы: миниатюры, иконки-документы |

На экранах до 640 px крупные радиусы уменьшаются (`[class*="rounded-[2rem]"]` →
`1.35rem` в `mobile.css`).

**Границы:** 1 px `border-ink/10`. Рамок в 2 px нет, кроме пунктирной дропзоны
(`border-2 border-dashed border-ink/15`).

**Тени:** только две плюс подъём при наведении.

| Тень | Значение | Где |
| --- | --- | --- |
| `shadow-soft` | `0 28px 80px rgba(23,24,21,.12)` | Большие карточки, редактор, статья |
| `shadow-card` | `0 12px 32px rgba(23,24,21,.08)` | Малые карточки при наведении, кнопки |

Интерактив поднимается: `transition hover:-translate-y-0.5` (или `-translate-y-1`
у больших карточек) плюс тень. Анимации короткие, 160 мс.

**Декор** (используйте дозированно, один-два приёма на экран):

- **Точечная сетка** на `body`: `radial-gradient(rgba(23,24,21,.06) .7px, transparent .7px)`, шаг 9 px.
  Обязательна на каждой странице; в страницах на `style.css` она в `body`, в
  остальных — классами `[background-image:…]` на `<body>`.
- **Линейная сетка** `.grid-lines` (28 px) для дропзон.
- **Кольца**: толстый круг-контур в углу карточки, `absolute -bottom-24 -right-16 h-64 w-64 rounded-full border-[44px] border-violet/25`
  (на лаймовой карточке — `border-ink/10`, на тёмной — `border-lime/20`).
- **Размытые пятна** в hero: `absolute … rounded-full bg-lime/30 blur-[100px]` и фиолетовое `bg-violet/10`.
- **Маркер под словом** в H1: лаймовая полоса `-rotate-2 rounded-full bg-lime` под текстом.
- **Бегущая строка** (`.marquee`): тёмная полоса с капсом и лаймовыми `✦`; уважает
  `prefers-reduced-motion`.
- **Стикер**: фиолетовая плашка, повёрнутая на 5°, с белым капсом.

Логотип — «хвост кита» (в названии зашита игра слов: ФНС + кит), без букв. Знак
рисуется на квадрате 198×198 со скруглением 38: лаймовый фон, фиолетовая волна позади,
тёмный хвост и тёмная вода спереди. Знак один на все размеры; он держится и на 16 px,
потому что состоит из трёх крупных пятен. Название рядом пишется текстом «ФНСКит».

| Файл | Что это |
| --- | --- |
| `images/logo.svg` | Знак. Шапки, подвалы, JSON-LD (`<img>` 32–40 px) и ссылка `rel="icon" type="image/svg+xml"` во всех страницах |
| `favicon.ico`, `images/favicon-16x16.png`, `images/favicon-32x32.png` | Растровые фавиконки (в ICO кадры 16, 32 и 48) |
| `images/apple-touch-icon.png` (180), `images/icon-192x192.png`, `images/icon-512x512.png` | Сплошной квадрат без прозрачных углов; в иконках PWA содержимое сжато до безопасной зоны круглой маски (maskable) |

Правила: не ставьте знак на цветные подложки (он сам плитка), не добавляйте в него
текст (на мелких размерах он не читается), держите вокруг знака свободное поле не
меньше четверти его ширины.

OG-картинка `images/og.png` — 1731×909, бумажный фон с точками, слово «ФНСКит» слева
сверху, заголовок крупно, справа лента документа с двумя плашками.

## 6. Компоненты

Ниже — готовые блоки с разметкой. Копируйте их как есть и меняйте тексты.

### Кнопки и ссылки-действия

Правило: **одно главное действие на экран** — тёмная кнопка; второстепенное —
«стеклянная». Шеврон `>` кладётся в `<span class="action-chevron">`, а не картинкой.

```html
<!-- Основная -->
<a href="/editor-dlya-fns" class="group inline-flex items-center gap-3 rounded-full bg-ink px-6 py-4 text-sm font-extrabold text-white transition hover:-translate-y-0.5 hover:shadow-card">
  Открыть редактор
  <span class="action-chevron action-chevron--centered grid h-7 w-7 place-items-center rounded-full bg-lime text-ink transition-transform group-hover:translate-x-1">&gt;</span>
</a>

<!-- Второстепенная («стекло») -->
<a href="/" class="rounded-full border border-ink/15 bg-white/70 px-4 py-3 text-sm font-bold backdrop-blur transition hover:border-ink hover:bg-white">На главную</a>

<!-- Лаймовая (призыв в шапке главной) -->
<a href="/editor-dlya-fns" class="rounded-full border border-lime bg-lime px-5 py-3 text-sm font-extrabold text-ink transition hover:-translate-y-0.5 hover:border-ink hover:bg-ink hover:text-white">Открыть редактор</a>

<!-- Текстовая ссылка со стрелкой -->
<a href="…" class="inline-flex items-center gap-2 text-sm font-extrabold text-violet">Открыть в редакторе <span class="action-chevron">&gt;</span></a>
```

На страницах на `style.css` те же роли выполняют `.header-cta`, `.header-link`,
`.inline-cta`, `.aside-cta a`.
Минимальная высота касания — 44 px (`mobile.css`).

### Шапки и подвалы

Шапок три варианта. Выбирайте по типу страницы:

| Тип страницы | Шапка | Подвал |
| --- | --- | --- |
| Главная, просмотрщик, редактор | Tailwind `<nav class="mx-auto flex max-w-[1440px] items-center justify-between px-5 py-5 sm:px-8 lg:px-12">`: логотип 40 px + слово, ссылки (скрыты до `md`), справа «стеклянная» ссылка и кнопка | Tailwind: логотип 32 px, оговорка «не является официальным продуктом ФНС России», ряд ссылок |
| Статья | `.site-header` + `.brand` + `.header-actions` (`.header-link`, `.header-cta`) | `.site-footer`: `© 2026 ФНСКит · независимый технический сервис` и навигация |
| Юридические и ошибки | `.legal-header` + `.legal-brand` + `.legal-back` | `.legal-footer`: копирайт и навигация |

На экранах до 640 px слово рядом с логотипом и вторичная ссылка скрываются.
В каждом подвале есть ссылка на политику ПДн (на главной, в редакторах и служебных
страницах — ещё и на согласие); контакт — `mailto:`.

### Hero страницы

- Главная: бейдж-«чип» над H1 (`rounded-full border border-ink/10 bg-white/70 px-3 py-2 text-xs font-extrabold`
  с фиолетовой точкой), H1 в три строки с лаймовым маркером под ключевым
  словом, лид `text-xl font-medium text-ink/60`, кнопка, четыре плитки-факта.
- Статья: `.article-hero` — лаймовая (или `.violet` — бледно-фиолетовая)
  подложка, внутри `.eyebrow`, `h1`, `.lead`, `.article-meta` из чипов
  (дата проверки, время чтения, основание).
- Юридическая страница: `.legal-hero` на лайме, `.legal-kicker`, `h1`, `.legal-meta`.

### Карточки

| Нужно | Берите |
| --- | --- |
| Малый факт (цифра + подпись) | `rounded-2xl border border-ink/10 bg-white/75 p-4 backdrop-blur`: цифра `text-2xl font-black tracking-[-0.05em]`, подпись `text-xs font-semibold text-ink/40` |
| Три преимущества | `rounded-2xl border border-ink/10 bg-white/85 p-5 shadow-[0_8px_24px_rgba(23,24,21,.04)] hover:-translate-y-0.5 hover:shadow-card`, иконка-квадрат 36 px (`bg-lime`, `bg-violet text-white` или `bg-ink text-lime`) |
| Шаги «01 / 02 / 03» | Три `article.bg-paper.p-7` в сетке с зазором `gap-px` на `bg-ink/10`; при наведении `hover:bg-lime` |
| Карточка-ссылка на инструкцию | `group relative flex min-h-[330px] flex-col rounded-[2rem] p-7 sm:p-9` + цвет поверхности + кольцо; внизу «Читать инструкцию >» с `mt-auto` |
| Технические параметры | `<dl>` с `grid-cols-2 sm:grid-cols-4 gap-px` на `bg-ink/10` и ячейками `bg-white/50 p-4` (dt — 9 px капс, dd — `text-sm font-extrabold`) |
| Спецификация в статье | `.spec-grid` из `.spec-card` (капс-подпись, крупное значение) |

### Блоки статьи (`style.css`)

```html
<section class="article-section" id="first">
  <h2>Заголовок секции</h2>
  <p>Текст…</p>

  <div class="quick-answer"><strong>Короткий ответ в первой строке.</strong> Пояснение…</div>
  <div class="note"><strong>Граница инструкции:</strong> что она не заменяет…</div>

  <ol class="steps"><li><strong>Шаг.</strong> Описание…</li></ol>
  <ul class="checklist"><li>Пункт с галочкой</li></ul>

  <div class="mistakes">
    <div class="mistake"><strong>Типичная ошибка</strong><p>Почему так нельзя.</p></div>
  </div>

  <a class="inline-cta" href="/editor-dlya-fns">
    <div><span>Когда нужен PDF или TIFF</span><strong>Собрать страницы и применить профиль ФНС</strong></div>
    <span class="action-chevron">&gt;</span>
  </a>

  <p class="source-line">Официальные источники: <a href="…" target="_blank" rel="noreferrer">…</a></p>
</section>

<section class="article-section" id="faq">
  <h2>Частые вопросы</h2>
  <div class="faq">
    <details><summary>Вопрос?</summary><div class="faq-answer">Ответ.</div></details>
  </div>
</section>
```

Назначение блоков:

- `.quick-answer` — тёмная плашка с лаймовым `<strong>`; ответ на главный вопрос
  секции. Не более одной на секцию.
- `.note` — бледно-фиолетовая плашка: оговорки, границы ответственности.
- `.steps` — нумерованный список с лаймовыми квадратами 48 px.
- `.checklist` — список с лаймовой галочкой.
- `.mistake` — карточка с фиолетовой левой полосой.
- `.inline-cta` — тёмная плашка-ссылка в тексте; одна на статью, рядом с местом,
  где сервис реально нужен.
- `.source-line` — серая строка с источниками под фактами и цифрами.
- Боковая колонка: `.article-aside` > `nav.toc` (якоря по `id` секций) и
  `.aside-cta` (лаймовая карточка с кнопкой). На экранах уже 900 px оглавление скрыто.

### Блоки юридических страниц

`.legal-section` с `h2`, `h3`, `p`, `ol/ul`, `.legal-note` (бледно-фиолетовая
плашка), `dl.legal-definition` (двухколонный список «термин — значение»),
`aside.legal-nav` (оглавление). Для печати уже есть правила `@media print`: шапка,
подвал и меню скрываются, фон белый.

Сейчас `privacy.html` и `consent.html` — короткие страницы-заглушки
в одну колонку с `noindex`. Настоящий документ собирайте из секций
`.legal-section` с уникальными `id`, добавьте `aside.legal-nav` со ссылками на них
и верните двухколоночную сетку (уберите инлайновый `grid-template-columns`).

Страницы ошибок используют тот же каркас, но в одну колонку:
`<main class="legal-layout" style="grid-template-columns:minmax(0,1fr)">`. Пути в них
**только абсолютные** (`/style.css`, `/images/…`): страница отдаётся под любым адресом.

### Кнопки и поля в кабинете

Кабинет (`account.html`, `js/account.js`) и страницы входа Keycloak живут по
одному правилу: **кнопки и поля ввода — «таблетки» (`rounded-full`), а
контейнеры скругляются крупнее и вложенно** — карточка 2rem, строка в ней
1.5rem, панель внутри строки 1.5rem. Тогда круглые кнопки не торчат из
квадратных рамок. Вид задан компонентными классами в `site/src/tailwind.css`:

| Класс | Что это |
| --- | --- |
| `.btn` + `.btn-primary` / `.btn-lime` / `.btn-secondary` / `.btn-ghost` / `.btn-danger` / `.btn-on-dark` | Кнопка. Одно главное действие на экран — `btn-primary`; рядом — `btn-secondary`; необратимое — `btn-danger` (без рамки, красный текст) |
| `.btn-sm` | Компактная кнопка внутри строк списка |
| `.field`, `.field-sm` | Текстовое поле и дата. Высота 48 / 40 px, фокус — фиолетовая рамка и кольцо |
| `.segmented` | Выбор из 2–4 вариантов («таблетки» на радио-кнопках). Выпадающий `<select>` не используем: его список рисует система, и стилям он не поддаётся |
| `.switch` | Переключатель `role="switch"` с `aria-checked` |
| `.chip` | Плашка-состояние: `bg-paper` — спокойно, `bg-lime/60` — скоро, `bg-[#FFDFA8]` — срочно, `bg-red-50` — просрочено |

Новый кабинетный экран не пишет эти формы заново, а берёт классы. Системные
`<select>` не используем вовсе, а `<input type="date">` без `.field` не оставляем. Страницы входа
Keycloak повторяют то же в `backend/keycloak/themes/fnskit/login/resources/css/fnskit.css`.

Принцип «воздуха»: одна колонка шириной до 960 px, один главный блок на экран,
второстепенное прячется (`<details>`, кнопка «Показать документы по
ситуации»), боковых колонок нет — безопасность и профиль вынесены на вкладку
«Аккаунт».


## 7. Рецепты

### Новая статья-инструкция

1. Скопируйте `kak-otvetit-na-trebovanie-fns.html` в `site/<slug>.html`. Slug —
   латиницей через дефисы, как существующие (`kak-otkryt-ip-onlayn`); в ссылках без `.html`.
2. В `<head>` замените `description`, `keywords`, `canonical`, весь блок `og:*`/`twitter:*`,
   `<title>` (формат: «Тема — уточнение», название бренда в заголовок не обязательно).
3. Обновите JSON-LD: `Article` (`headline`, `datePublished`, `dateModified`) и
   `BreadcrumbList` (две позиции: «Главная» и страница).
4. В теле: `eyebrow` (рубрика), `h1`, `lead`, три чипа в `.article-meta`, секции с
   уникальными `id`. На каждый `id` — ссылка в `nav.toc`. Одна `.quick-answer`,
   одна `.inline-cta` (ведёт в редактор), в конце `faq`.
5. Каждый факт про требования, сроки и числа сопровождайте `.source-line`
   с официальным источником.
6. Добавьте ссылку в подвал, при необходимости карточку в `#guides` на главной
   (цвет выберите так, чтобы соседи чередовались). Пока сайт закрыт от индексации,
   в `<head>` оставьте `<meta name="robots" content="noindex,nofollow">`, а
   `sitemap.xml` не ведётся (раздел 12).
7. Пересоберите CSS (`npm run build`), если использовали новые утилиты Tailwind.

### Новая страница-приложение или инструмент

Основа — `tiff-viewer.html` (одна колонка 1240 px, дропзона, результат) или
редакторы (двухколоночный экран с тёмной боковой панелью `bg-ink rounded-[2rem]`).
Логику кладите в `site/js/<имя>.js` (IIFE, без глобалов, обращения к DOM через
`document.getElementById`), подключайте через `<script defer>`; внутреннюю
работу с большими файлами оставляйте в браузере. Страница-«не для индекса»
получает `<meta name="robots" content="noindex,nofollow">`, как и все страницы сейчас.

### Новая юридическая или служебная страница

Копируйте любую заглушку (`privacy.html`) или `404.html`: шапка `.legal-header`,
`.legal-hero`, `.legal-content`, подвал `.legal-footer`. Для длинного документа
разверните секции и оглавление, как описано в разделе 6. Служебные страницы без
пользы для поиска — `noindex,nofollow`. Подключите `style.css`, а Tailwind-CSS можно
не подключать, если не нужны утилиты. Текст согласия сверяется по версии: меняя
его, поднимите `consentVersion` в `js/editor.js` и `personal_data_consent_version`
в `backend/processor/app/main.py` (совпадение проверяет
`backend/processor/tests/test_consent.py`).

### Новая страница ошибки

Как `404.html`: абсолютные пути, `noindex,nofollow`, одна колонка. Пропишите
код в `nginx.conf` через `error_page` и `location = /<код>.html { internal; }`,
добавьте файл в `COPY` в `site/Dockerfile`, если у него нестандартное имя.

### Если нужен новый тип файла или каталог

`site/Dockerfile` копирует в образ только перечисленное: `*.html`, `*.ico`,
`style.css`, `mobile.css`, `fonts.css`, `robots.txt`, `site.webmanifest`, каталоги `images/`, `fonts/` и собранный `dist/`. Новый файл
вне этого списка в образ не попадёт, пока не добавите строку `COPY`.

## 8. Тексты и тон

- Русский, на «вы», без канцелярита и без обещаний, которых сервис дать не
  может. Фразы вида «в три клика» не используем.
- Честные границы всегда на виду: «ФНСКит не является официальным сервисом ФНС»,
  «не заменяет консультацию бухгалтера или юриста». Они есть в подвале и в
  `.note` внутри статей.
- Заголовки — короткие утверждения с точкой («Параметры — на нас.»,
  «У каждой задачи — свой профиль.»). Eyebrow над ними — рубрика или тезис
  одной фразой.
- Кнопки — глагол + объект: «Открыть редактор», «Подготовить файлы»,
  «Скачать TIFF».
- Параметры называем так, как их называет ФНС: DPI, цвет, сжатие, число страниц.
- Правовые и налоговые утверждения подкрепляем ссылкой на источник и датой
  проверки в `.article-meta`.

## 9. Доступность и поведение

- Язык страницы — `<html lang="ru">`. Декоративные логотипы и иконки —
  `alt=""` или `aria-hidden="true"`; смысловая ссылка-логотип получает
  `aria-label="ФНСКит — на главную"`.
- Навигации — с `aria-label`; группа переключателей — `role="group"` + `aria-pressed`;
  динамические сообщения — `aria-live="polite"`.
- Цель касания не меньше 44 px (`mobile.css` задаёт `min-height: 44px` для кнопок и полей).
- Видимый фокус нельзя убирать; у полей ввода — рамка и кольцо `violet`.
- Анимации отключаются при `prefers-reduced-motion: reduce` (глобальное правило
  в `style.css` и в `<style>` главной).
- Контраст: основной текст `ink` на `paper`/белом — высокий; вторичный текст ниже
  `ink/40` для смысловых подписей не опускайте, там он только для декоративных подсказок.
- Страница должна работать без наведения: подсказки и состояния не прячем за `hover`.

## 10. Известные несоответствия

Это не образец, а долг; не копируйте эти места в новый код.

- Цвета в разметке заданы hex-ами (`#DDD9FF` 16 раз), а не токенами. Стоит завести
  токены `lavender` (`#DDD9FF`) и `sand` (`#FFDFA8`) в `tailwind.config.js`.
- Лайм задан тремя близкими значениями: `#C8FF32` (токен), `#C8FF18` и `#D8FF58`
  (маркер на главной).
- Три разные шапки и три разных подвала (см. раздел 6). Единый компонент
  упростил бы поддержку.
- Крупный `<style>` внутри `index.html` и инлайн-стили в редакторах; перенести в
  `style.css`.
- Юридические стили в `style.css` записаны в одну строку (минифицированы вручную).
- Комментарий в `mobile.css` про «временный» Tailwind CDN устарел.
- В шапке главной указано «1 бит · Group 4», а профиль «НДС и требования»
  работает с 8-битным серым и LZW. Тексты и плитки нужно привести к одному виду.
- Метрика, логирование и резервные копии убраны из репозитория. При возврате
  метрики придётся расширить CSP и обновить раздел 9 политики ПДн.

## 12. Индексация

Сайт закрыт от индексации: это прототип, поисковикам он не нужен. Закрытие
сделано в трёх местах, чтобы один пропуск не открыл его:

| Где | Что |
| --- | --- |
| `site/robots.txt` | `User-agent: *` и `Disallow: /` |
| каждая страница `site/*.html` | `<meta name="robots" content="noindex,nofollow" />` |
| `site/nginx.conf` | заголовок `X-Robots-Tag: noindex, nofollow, noarchive` на любой ответ, включая картинки и JSON API |

`sitemap.xml` удалён (вместе со строкой в `Dockerfile` и `location` в `nginx.conf`):
карта сайта с закрытыми страницами только путает роботов. Домен сайта —
`fnskit.sherhn.space`, он прописан в `canonical`, `og:*`, JSON-LD и в
`.env.example`.

Чтобы открыть сайт, сделайте всё вместе:

1. В `robots.txt` замените `Disallow: /` на `Allow: /` и оставьте
   `Disallow: /api/`; добавьте строку `Sitemap: https://fnskit.sherhn.space/sitemap.xml`.
2. На публичных страницах (главная, статьи, редакторы для ФНС и регистрации,
   просмотрщик) поставьте `content="index,follow,max-image-preview:large"`.
   Служебные страницы (ошибки, юридические заглушки, `editor-custom`)
   оставьте с `noindex,nofollow`.
3. Уберите строку `X-Robots-Tag` из `nginx.conf`.
4. Верните `sitemap.xml` (`<url>` с `loc`, `lastmod`, `changefreq`, `priority`),
   добавьте его в `COPY` в `site/Dockerfile` и `location = /sitemap.xml { expires 1h; }`
   в `nginx.conf`.
5. Пересоберите образ `nginx` и проверьте ответ: `curl -sI https://fnskit.sherhn.space/`
   не должен содержать `X-Robots-Tag: noindex`.
